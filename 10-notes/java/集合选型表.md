# 集合选型表

> 判断顺序：先问并发吗？不并发用 HashMap/ArrayList；并发再问读写比例。

| 容器 | 锁机制 | 适用场景 | 为什么不选别的 |
| :---: | :---: | :---: | :---: |
| HashMap | 无锁 | 单线程 | 并发情况会丢失数据 |
| Hashtable | 全表锁 | 已淘汰，面试提一句 | 高并发时性能差 |
| Collections.synchronizedMap | 全表锁（包装器） | 简单同步需求 | 多写时竞争激烈 |
| ConcurrentHashMap | 桶级锁+CAS | 读写都频繁 | - |
| CopyOnWriteArrayList | 写时复制 | 读多写少 | 写多时要复制全数组代价大 |
