# HashMap 扩容与树化

## 一句话结论

> 默认 16，负载因子 0.75，扩容翻倍；链表长度 ≥ 8 且容量 ≥ 64 才树化，否则只扩容。

## 边界与坑

| 场景 | 会发生什么 | 怎么规避 |
|---|---|---|
| 初始容量传 10 | 实际 16（取 2 的幂） | 预估容量用 `expectedSize / 0.75 + 1` |
| key 为 null | 放第 0 桶 | — |
| 并发 put | JDK7 死循环，JDK8 丢数据 | 并发场景换 ConcurrentHashMap |
